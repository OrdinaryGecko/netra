# Netra Frontend

React admin console for Netra.

## Local Development

Start Rails from the repo root on `localhost:3000`, then run:

```bash
npm install
VITE_API_BASE_URL=http://localhost:3000 npm run dev
```

Open:

```text
http://localhost:8080
```

## Build

```bash
npm run build
```

The production build is written to `frontend/dist`.
